# 交接稿的遮蔽規則

交接會發在同仁看得到的指揮台上，這份規則是它唯一的防線。發之前逐類過一遍；拿不準算不算 → 當成要遮。

## 一、整段換掉

原文**一個字都不留**：不留前幾碼、後幾碼，不留長度，不寫「以 xxx 開頭」。部分保留也是外洩，拼湊幾則交接就能還原。

| 類別 | 例子 | 換成 |
|---|---|---|
| 權杖、API key | 存取權杖、服務金鑰、bot 權杖、refresh 權杖 | `[已遮蔽：權杖]` |
| 密碼 | 帳號密碼、資料庫密碼、壓縮檔密碼 | `[已遮蔽：密碼]` |
| 私鑰、憑證內容 | SSH 私鑰、簽章私鑰、憑證檔內文 | `[已遮蔽：私鑰]` |
| 帶密鑰的網址或連線字串 | 查詢參數裡的 `token=`、`key=`、`sig=`；`使用者:密碼@主機` 形式 | 整條網址換成 `[已遮蔽：帶密鑰的網址]` |
| cookie、session 值 | 登入 cookie、session id | `[已遮蔽：session]` |
| 電話 | 手機、市話、分機 | `[已遮蔽：電話]` |
| 電子郵件地址 | 私人或公司信箱 | `[已遮蔽：信箱]` |
| 身分識別號碼 | 身分證、護照、居留證號碼 | `[已遮蔽：證號]` |
| 金融帳號 | 銀行帳號、信用卡號 | `[已遮蔽：帳號]` |
| 住址 | 住家或寄送地址 | `[已遮蔽：住址]` |
| 生日 | 出生日期 | `[已遮蔽：生日]` |

- 指令範例裡出現密鑰，連指令一起改寫成不含值的樣子，例如寫「用存取權杖呼叫」，不貼那條指令。
- 要讓接手的人拿到密鑰：寫「存在哪個密碼庫的哪一項」，不寫值。

## 二、整句不寫

不是遮，是根本不放進交接：

- 私事：健康、家庭、財務、情緒、私人行程。
- 對同仁的評價、考核、人事安排。
- 只有擁有者本人該知道、跟接手這件工作無關的事。

## 三、可以保留

- 工作上的稱呼：GitHub 帳號、職稱、角色（「開票的人」「驗證者」）。
- 票、PR、commit 的連結與 SHA。
- 公開的 noreply 提交信箱。

## 四、發前自查

讀回交接稿時，對照上面兩張表逐類找一次；對話裡出現過的每個密鑰與個資，在稿子裡搜它的原文，必須搜不到。
